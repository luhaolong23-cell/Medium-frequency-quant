# System Flow

## Purpose

This document describes the target end-to-end operating flow of the system.

It covers the final product direction:

`市场牛熊判断 -> 优质股筛选 -> 观察池 -> 买点信号 -> 执行 -> 持续监控`

It does not imply that every stage is already implemented in the current codebase. At present, the implemented skeleton still stops at the market-regime layer.

## Daily decision layer

The daily decision layer is the main decision-making loop of the system.

1. Update global market data.
2. Determine which country or region markets are in a bull regime.
3. Refresh the stock universe inside bull markets only.
4. Run quality selection on the bull-market stock pool.
5. Update the watchlist with high-quality candidates.
6. Scan technical entry conditions for watchlist names.
7. Generate daily buy and sell plans.

In this layer:

- `市场牛熊判断` means judging country or region market state.
- `优质股筛选` means selecting quality stocks inside bull markets.
- `观察池` means quality candidates that are not yet positions.
- `买点信号` means technical conditions that trigger actual execution.

## Intraday execution and monitoring layer

The intraday layer does not redefine the strategy. It executes and supervises the plan generated by the daily layer.

1. Execute planned buy or sell orders.
2. Track order status and fill progress.
3. Track position anomalies after entry.
4. Track risk-rule triggers.
5. Track market invalidation or signal reversal.

In this layer:

- `执行监控` means order and fill monitoring.
- `持仓监控` means monitoring position state and post-entry risk.
- `持续监控` means intraday execution and risk supervision, not high-frequency discretionary watching.

## Cadence definition

The intended cadence is:

- `日频`
  market selection, stock selection, watchlist updates, and signal evaluation
- `盘中`
  execution, order tracking, position tracking, and risk alerts

This is the system's default definition of a mid-frequency workflow.

## Current implementation note

The current codebase implements only the early part of the flow:

- market reference data
- market observations and features
- market regime decision
- orchestrator skeleton

The remaining layers are planned extensions.
